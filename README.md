# 전체 일정 관리

학생이 학업, 과제, 개인 일정을 한곳에 정리하고 진행 상황을 확인할 수 있는 반응형 To-Do 앱입니다. 할 일의 마감 날짜를 지정하고, 완료 여부와 남은 일정을 한눈에 확인할 수 있습니다.

## 주요 기능

- 할 일 추가, 수정, 개별 삭제 및 완료 상태 변경
- 마감 날짜 지정 및 수정, 지난 미완료 일정 표시
- 전체 / 진행 중 / 완료됨 필터
- 남은 할 일, 전체·완료·진행 중 개수와 진행률 표시
- 완료된 항목 전체 삭제
- 브라우저 `localStorage`에 할 일과 선택한 필터 저장
- 빈 입력 방지, 필터별 빈 상태 안내, 삭제 전 확인
- HTML 태그를 포함한 입력도 텍스트로 안전하게 표시
- 화면 크기에 맞춰 배치가 바뀌는 반응형 UI

## 어떻게 만들었나요

먼저 [PRD.md](./PRD.md)에 목표, 기능, 상태, 예외 처리, 저장 방식과 완료 기준을 정리했습니다. 그 요구사항을 바탕으로 Bootstrap 5와 Tailwind CSS 버전을 각각 만들고, 완료 기준과 화면·마크업 차이를 비교한 뒤 Tailwind 버전을 선택했습니다. 이후 선택한 버전에 날짜 지정, 삭제 확인, 요약 정보와 완료 축하 효과 등 사용성을 보완하는 기능을 더했습니다.

실습 과정과 브랜치 사용 방법은 [guide.md](./guide.md)에서 확인할 수 있습니다.

## Bootstrap vs Tailwind

두 버전 모두 같은 할 일 관리 기능을 목표로 하지만, 화면 스타일을 지정하는 방법이 다릅니다.

| 항목 | Bootstrap | Tailwind CSS |
| --- | --- | --- |
| 스타일 적용 방식 | `btn`, `card`, `form-control` 등 미리 준비된 컴포넌트와 클래스를 조합 | `flex`, `rounded-xl`, `text-slate-700`처럼 작은 유틸리티 클래스를 조합 |
| HTML의 class | 역할을 나타내는 비교적 짧은 클래스 중심 | 간격, 색상, 크기 등 세부 표현을 클래스에 직접 지정 |
| 장점 | 기본 컴포넌트로 빠르게 일관된 화면을 구성 | HTML에서 요소별 스타일을 세밀하게 조정하기 쉬움 |

최종 버전은 Tailwind CSS를 사용합니다. 화면의 여백, 색상, 반응형 배치 등을 요소별로 바로 조정할 수 있어 현재 디자인을 구성하고 다듬기에 적합했습니다.

## 실행 방법

브라우저에서 [GitHub Pages 배포 페이지](https://ehdgns33.github.io/26-w08-todo/)를 열어 사용할 수 있습니다.

로컬에서 확인하려면 저장소 루트에서 간단한 웹 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다. 앱은 Tailwind CSS를 CDN으로 불러오므로 실행 시 인터넷 연결이 필요합니다.

## 커스터마이징한 부분

- 각 할 일에 날짜를 추가하고, 기존 일정의 날짜도 수정할 수 있도록 했습니다. 날짜가 지난 미완료 일정은 별도 색상으로 표시합니다.
- 목록 삭제와 완료 항목 전체 삭제 전에 확인 대화상자를 표시해 실수로 지우는 일을 줄였습니다.
- 전체 일정, 완료, 진행 중 개수와 진행률을 함께 보여주도록 요약 영역을 추가했습니다.
- 할 일을 완료하면 축하 효과를 표시하고, 동작 줄이기 설정을 사용하는 경우에는 애니메이션을 숨깁니다.
- 저장 데이터와 날짜 입력을 검증하고, 저장소 오류를 화면에 안내합니다.
